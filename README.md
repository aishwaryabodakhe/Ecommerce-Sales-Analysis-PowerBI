🛒 E-Commerce Sales Analysis Dashboard – Power BI

📌 Project Overview

This project is an interactive E-Commerce Sales Analysis Dashboard developed using Microsoft Power BI.

The dashboard provides insights into sales performance, profit, quantity, average order value, customer performance, payment modes and product categories. It helps analyze business performance through interactive visualizations and filters.

🎯 Project Objectives

- Analyze total sales, profit and quantity.
- Monitor average order value.
- Understand state-wise sales performance.
- Analyze payment mode distribution.
- Identify customer-wise sales performance.
- Explore product category and sub-category performance.
- Track profit across order dates.

📊 Key Performance Indicators

- Total Sales: 102K
- Total Profit: 7K
- Total Quantity: 1K
- Average Order Value (AOV): 27.60K

📈 Dashboard Analysis

- Sales Amount by State
- Quantity by Payment Mode
- Profit by Order Date
- Sales Amount by Customer Name
- Quantity by Category
- Profit by Sub-Category

🎛️ Interactive Filters

- Order Date
- State
